      Organizer console

      This gate protects the organizer actions (result corrections, start-fresh, PIN change). It is a local UI gate on a single file with no server — it stops a teammate from casually tampering, it is not credential-grade authentication. Every action taken here is permanently recorded in the audit trail, with the actor label.

      Locked out? Reset the PIN back to 1234 (audited).

      Control board

      The whole event at a glance — the stage, how much is decided, who's leading, and the single next result to call. Read-only: nothing on this board changes the tournament.

      Correct a decided result

      The only way a decided game ever changes. Pick the game, pick who should win — the change re-flows the standings and the bracket, and is audited (previous winner included).

      Change the organizer PIN

      Stored only as a hash (the clear PIN never touches localStorage). The PIN survives a start-fresh; changing it is audited.

      Archive & start a fresh tournament

      This does NOT wipe history: the whole tournament (schedule, results, full audit trail) is archived first, then a clean Phase-1 state begins. The reset itself is the first audited entry of the new tournament. Archives stack — history is never lost.
